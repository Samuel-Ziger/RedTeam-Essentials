# Política de segurança

## Versões suportadas

A branch principal e a versão mais recente publicada recebem correções. O
conteúdo ofensivo é educacional; uma técnica documentada não é, por si só,
uma vulnerabilidade do projeto.

## Como reportar

Não abra uma issue pública para credenciais expostas, fuga do isolamento do
laboratório ou execução de código inesperada. Use o recurso **Report a
vulnerability** do GitHub na aba Security do repositório. Inclua:

- versão ou commit afetado;
- pré-condições e impacto;
- reprodução mínima e segura;
- sugestão de correção, se houver.

Não inclua dados de terceiros, tokens válidos ou evidências não sanitizadas.
O mantenedor confirmará o recebimento e coordenará a divulgação responsável.
