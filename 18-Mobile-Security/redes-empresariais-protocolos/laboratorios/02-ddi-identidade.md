# Lab 02 — DDI, identidade e dependências

Desenhe IPAM hierárquico, DNS recursivo/autoritativo, DHCP relay/failover, NTP,
PKI e AAA para três sites. Construa grafo de dependências e identifique ciclos.

**Aceite:** existe bootstrap sem DNS/tempo perfeito, certificados têm renovação
e alerta, falha AAA possui comportamento definido e logs usam horário confiável.
