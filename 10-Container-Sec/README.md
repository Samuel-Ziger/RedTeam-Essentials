# 10 — Windows empresarial I: endpoints e Windows Server

> Administração empresarial do zero: Windows Server, Server Core, storage,
> política, Defender, servicing, recuperação, Hyper-V e estado desejado.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Suporte corporativo, administradores e engenheiros de plataforma. |
| Pré-requisitos | Módulos 08 e 09. |
| Tempo estimado | 180–280 horas. |
| Ambiente | Windows Server 2025 evaluation/versão suportada em VMs sem NIC. |
| Evidência final | Baseline, estado desejado, restore e servidor standalone. |
| Critério de conclusão | Operar e reconstruir o workload local por runbook. |

## Curso principal

A rota está em
[windows-empresarial-fundamentos/](windows-empresarial-fundamentos/README.md).
Os 19 capítulos ensinam edições/licenciamento, Server Core, gerenciamento e
PowerShell, roles/features, identidades/direitos, baseline, NTFS/ReFS/Storage
Spaces/FSRM, auditoria, Defender, update, VSS/backup, Hyper-V, containers locais,
DSC e capacity planning.

## Fronteira com redes

Não há IP, DNS, DHCP, firewall, SMB remoto, WinRM, cluster ou domínio. O curso
explica onde essas dependências entram e entrega contratos para a etapa futura.
