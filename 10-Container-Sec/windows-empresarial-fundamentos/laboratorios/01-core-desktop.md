# Lab 01 — Server Core e Desktop Experience

Instale duas VMs da mesma build/edição, uma Core e outra Desktop Experience.
Compare disco, processos, features, update, ferramentas locais e superfície de
servicing. Execute o baseline em ambas e documente operações equivalentes.

**Aprovação:** decisão baseada em requisito de workload, não em preferência;
snapshots limpos e nenhuma conectividade criada.
