# Windows empresarial I — endpoints e Windows Server

Formação para operar Windows em organizações: ciclo de vida, Windows Server,
Server Core, roles/features, armazenamento, auditoria, Defender, atualizações,
backup, Hyper-V e configuração como código. O laboratório é inteiramente local.

## Contrato de aprendizagem

| Campo | Definição |
|---|---|
| Nível | Administrador Windows iniciante a intermediário |
| Duração | 180–280 horas |
| Pré-requisito | Módulos 08 e 09 |
| Ambiente | Windows Server 2025 evaluation/versão suportada em VMs sem NIC |
| Evidência | Baseline, runbooks, restauração e servidor standalone final |
| Conclusão | Administrar e recuperar servidor local com mudança auditável |

## Fronteira com redes

O curso não configura IP, DNS, DHCP, SMB remoto, firewall, WinRM, cluster,
domínio ou acesso remoto. Funções que dependem desses fundamentos são
identificadas e retomadas depois do módulo próprio de redes.
