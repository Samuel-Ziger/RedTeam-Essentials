# Glossário

- **Component Store:** componentes/manifests usados pelo servicing.
- **Desktop Experience:** instalação Server com GUI completa.
- **DSC:** mecanismo de configuração declarativa e convergência.
- **FSRM:** quotas, file screening, classificação e relatórios de arquivos.
- **Hotpatch:** atualização sem reinício em cenários suportados.
- **Production checkpoint:** checkpoint que busca consistência de workload.
- **ReFS:** filesystem voltado a integridade/escala em cenários suportados.
- **Role/feature:** função de servidor e componente de suporte.
- **Server Core:** opção de instalação com GUI reduzida.
- **Storage Spaces:** virtualização de armazenamento sobre discos/pools.
- **VHDX:** formato moderno de disco virtual Hyper-V.
- **VSS:** coordena snapshots com writers/requesters/providers.
- **Workload:** serviço de negócio completo executado na infraestrutura.
