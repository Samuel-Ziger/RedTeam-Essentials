# 20 — Criptografia II: primitivas modernas, chaves e assinaturas

Segunda etapa da formação: AES, ChaCha20, AEAD, RSA, curvas elípticas, troca de
chaves, assinaturas e formatos híbridos. O foco é usar bibliotecas maduras com
parâmetros seguros e formatos versionados, sem inventar algoritmos.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Desenvolvedores e profissionais de segurança com os fundamentos do módulo 19. |
| Pré-requisitos | Módulos 00, 02 e 19. |
| Tempo estimado | 160–240 horas. |
| Ambiente | Python, biblioteca `cryptography` e dados sintéticos exclusivamente locais. |
| Evidência final | Envelope AEAD versionado, troca de chaves e assinatura com testes negativos. |
| Critério de conclusão | Escolher e compor primitivas modernas sem reutilizar nonce, chave ou contexto. |
