# Criptografia II — primitivas modernas

Esta etapa conecta fundamentos a algoritmos reais. Os exemplos usam APIs de
alto nível, formatos autenticados e chaves descartáveis. Implementações
didáticas nunca substituem bibliotecas mantidas e revisão especializada.
