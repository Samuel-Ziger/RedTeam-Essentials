# 30 — Web, APIs e revisão segura de código

Este módulo integra descoberta web, testes locais de aplicações e APIs,
modelagem de ameaças e revisão de código. Os exemplos vulneráveis devem ser
executados somente no laboratório fornecido.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Desenvolvimento, QA, AppSec, revisão de código e pentest autorizado. |
| Pré-requisitos | Módulos `27`, `28` e `29`. |
| Tempo estimado | 60–90 horas. |
| Ambiente | DVWA, Juice Shop, VAmPI e aplicações próprias em rede local isolada. |
| Foco | Causa-raiz, validação controlada, correção e teste de regressão. |
| Evidência final | Relatório AppSec com reprodução mínima, patch e reteste. |
| Critério de conclusão | Labs locais concluídos e pelo menos um defeito corrigido com regressão. |
