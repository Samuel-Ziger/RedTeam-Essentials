# 34 — Segurança de plataformas: macOS, mobile e wireless

Esta etapa compara três superfícies que combinam endpoint, identidade,
aplicações e comunicação sem fio. A prioridade é entender fronteiras de
confiança e produzir validações defensivas reproduzíveis.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Segurança de endpoints, mobile, wireless, MDM e Purple Team. |
| Pré-requisitos | Módulos `27`, `30` e `31`; base macOS `12`–`13`. |
| Tempo estimado | 24–36 horas. |
| Ambiente | Dispositivos próprios, emuladores e rede sem fio de laboratório. |
| Foco | Modelo de segurança, gestão, aplicações, telemetria e hardening. |
| Evidência final | Baseline comparativa e plano de validação por plataforma. |
| Critério de conclusão | Baselines das três plataformas avaliadas e desvios priorizados. |
