# macOS, mobile e wireless

Esta rota compara modelos de plataforma sem misturar suas garantias. Para cada
uma, identifique raiz de confiança, distribuição de software, armazenamento de
segredos, telemetria e resposta a incidentes.

## Sequência

| Plataforma | Material | Pergunta central |
|---|---|---|
| macOS | [Segurança de macOS](LEGADO-MACOS-SECURITY.md) | Como assinatura, TCC, MDM e observabilidade se combinam? |
| Mobile | [Segurança mobile](LEGADO-MOBILE-SECURITY.md) | Como sandbox, permissões, armazenamento e backend dividem a confiança? |
| Wireless | [Segurança wireless](LEGADO-WIRELESS-SECURITY.md) | Como autenticação, criptografia, segmentação e RF alteram o risco? |

## Entrega

Construa uma baseline comparativa com propriedade do dispositivo, configuração
esperada, evidência coletável, desvio, resposta e limitação. Testes sem fio
ficam restritos ao ambiente e aos dispositivos do laboratório.
