# 18 — Ameaça quântica sem sensacionalismo

Um computador quântico criptanaliticamente relevante ameaçaria RSA, DH e ECC
via Shor; Grover reduz aproximadamente o expoente de busca simétrica, tratável
com tamanhos adequados. Não existe data confiável para essa máquina.

O risco já importa para dados de longa confidencialidade: “coletar agora,
decifrar depois”. Priorize inventário, vida do dado, dependências e agilidade.
Pós-quântica usa algoritmos clássicos resistentes aos ataques quânticos
conhecidos; não é o mesmo que QKD.

## Prática

Classifique sistemas por longevidade do dado, tempo de migração e exposição.
