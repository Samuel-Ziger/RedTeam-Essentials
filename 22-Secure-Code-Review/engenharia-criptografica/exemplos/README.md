# Ferramentas e protocolo

| Artefato | Finalidade |
|---|---|
| [crypto_inventory.py](crypto_inventory.py) | Valida e prioriza inventário JSON offline. |
| [secure_record.py](secure_record.py) | Registros AES-GCM ordenados e versionados. |

O inventário não promete detectar criptografia automaticamente. O protocolo é
uma referência educacional local: produção deve adotar protocolo padronizado e
revisado, não expandir este exemplo.
