# Glossário

- **Crypto agility:** capacidade controlada de substituir criptografia sem perder segurança/operação.
- **Cryptoperiod:** intervalo autorizado de uso de uma chave.
- **HSM/KMS:** módulo físico/serviço de gestão e operação com chaves.
- **IND-CCA:** noção de confidencialidade contra ciphertext escolhido.
- **KEM:** mecanismo de encapsulamento de chave.
- **ML-KEM:** KEM pós-quântico padronizado no FIPS 203.
- **ML-DSA:** assinatura pós-quântica padronizada no FIPS 204.
- **SLH-DSA:** assinatura hash-based padronizada no FIPS 205.
- **PQC:** criptografia pós-quântica executada em computadores clássicos.
- **SBOM/CBOM:** inventários de componentes de software/criptográficos.
