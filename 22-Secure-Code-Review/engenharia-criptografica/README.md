# Criptografia IV — engenharia, operação e pós-quântica

A última etapa ensina a avaliar um sistema completo, não apenas seu algoritmo.
O resultado esperado é um projeto revisável, inventariado, testável e capaz de
migrar de primitiva sem perder dados ou interromper o serviço.
