# Laboratórios do módulo 00

Os laboratórios verificam a capacidade de aplicar os capítulos sem repetir uma
receita. Eles usam apenas o computador local e dados sintéticos.

| Lab | Competência principal | Entrega |
|-----|-----------------------|---------|
| 01 | lógica, decisões, laços e testes de limite | classificador de consumo |
| 02 | CLI, Git e comparação de linguagens | analisador de notas em duas linguagens |
| 03 | estruturas, persistência e engenharia | agenda CLI testada |
| 04 | HTTP, API, SQLite e concorrência | serviço local com contrato |
| 05 | Docker, Nginx e operação | TaskBoard executado e defendido |

O Lab 04 fornece um [starter HTTP mínimo](starter-http/) para eliminar o salto
entre snippets e o primeiro servidor testado. O Lab 05 produz as evidências
guiadas das fases A–B do Projeto 4; sua melhoria autoral completa as fases C–D.

Cada laboratório deve ser feito em diretório próprio. Preserve código, testes,
comandos e relatório. Não use credenciais, dados pessoais nem serviços externos.

Uma entrega válida inclui:

1. contrato de entrada, saída e erro;
2. implementação explicada;
3. testes que exercitam caminho comum e limites;
4. registro de pelo menos uma falha investigada;
5. instruções de execução e cleanup;
6. reflexão sobre decisões e limitações.

Os exemplos do curso podem ser consultados depois da primeira tentativa. Se você
copiar uma solução, reconstrua-a sem olhar e explique cada decisão.
