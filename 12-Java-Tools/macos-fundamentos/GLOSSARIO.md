# Glossário

- **APFS:** sistema de arquivos da Apple baseado em containers, volumes,
  clones e snapshots.
- **Apple Silicon:** SoC da Apple que usa a arquitetura arm64.
- **Bundle:** diretório com estrutura padronizada apresentado como um objeto,
  como `Aplicativo.app`.
- **Data volume:** volume gravável que guarda dados do usuário e do sistema.
- **FileVault:** criptografia do volume de dados com integração ao login.
- **Finder:** gerenciador gráfico de arquivos do macOS.
- **Gatekeeper:** avalia procedência, assinatura e notarização de software.
- **LaunchAgent:** job do `launchd` executado no contexto de uma sessão.
- **LaunchDaemon:** job de sistema, independente de login interativo.
- **RecoveryOS:** ambiente separado para diagnóstico, reinstalação e política de boot.
- **Rosetta 2:** tradução de software Intel para Apple Silicon quando suportada.
- **Secure Enclave:** subsistema isolado para operações e chaves sensíveis.
- **SIP:** System Integrity Protection; limita alterações em partes protegidas.
- **SSV:** Signed System Volume; volume do sistema selado e verificado.
- **TCC:** Transparency, Consent and Control; governa acesso a dados e sensores.
- **Unified Log:** sistema central de logs estruturados do ecossistema Apple.
- **xattr:** atributo estendido associado a um arquivo, inclusive quarentena.
