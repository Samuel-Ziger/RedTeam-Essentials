# 04 — Interface, Finder e Ajustes do Sistema

A interface é uma visão do sistema, não um sistema separado. Finder manipula
arquivos; Dock inicia e organiza; Spotlight indexa; Mission Control organiza
janelas; Ajustes do Sistema expõe políticas e preferências.

## Modelo mental

- fechar uma janela não necessariamente encerra o aplicativo;
- itens na barra lateral são atalhos, não novas cópias;
- Lixeira não é backup;
- extensões podem estar ocultas, mas fazem parte do nome;
- permissão solicitada por um app é uma decisão de segurança.

Use `Command-Space` para localizar ferramentas pelo nome e `Command-Option-Esc`
somente quando um app não responde. Primeiro tente salvar e encerrar normalmente.

## Prática

Crie uma pasta de fixture, altere a visualização, mostre extensões, use tags e
Spotlight, mova o arquivo para a Lixeira e restaure. Registre o caminho real com
`pwd` no Terminal aberto a partir da pasta.
