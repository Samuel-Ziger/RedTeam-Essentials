# 39 — Threat intelligence e adversary emulation

O módulo transforma informação sobre ameaças em hipóteses testáveis,
planos de emulação seguros e melhorias defensivas mensuráveis.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | CTI, SOC, detecção, Red, Blue e Purple Team. |
| Pré-requisitos | Módulos `27`, `32`, `35` e `38`. |
| Tempo estimado | 20–32 horas. |
| Ambiente | Evidências públicas, fixtures e laboratório isolado. |
| Foco | Requisitos de inteligência, confiança, ATT&CK, emulação e feedback. |
| Evidência final | Pacote CTI com fontes, hipóteses, plano Purple e resultados. |
| Critério de conclusão | Pacote CTI revisado e hipótese emulada com retorno defensivo. |
