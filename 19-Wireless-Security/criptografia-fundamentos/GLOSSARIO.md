# Glossário

- **AEAD:** cifra que fornece confidencialidade e integridade, inclusive para dados associados.
- **CSPRNG:** gerador pseudoaleatório adequado a material criptográfico.
- **Digest:** saída de uma função hash.
- **Entropia:** medida ligada à incerteza de uma distribuição, não sinônimo de tamanho.
- **HMAC:** construção de autenticação de mensagem baseada em hash e chave.
- **IV:** valor inicial definido por um modo de operação.
- **KDF:** função que deriva material de chave para um propósito.
- **MAC:** código de autenticação de mensagem com chave compartilhada.
- **Nonce:** valor que não deve se repetir no escopo definido pelo algoritmo.
- **Salt:** valor público e individual que separa instâncias de uma KDF.
- **Tag:** autenticador produzido por MAC ou AEAD.
- **Vetor de teste:** entrada e saída esperada usadas para interoperabilidade.
