# 00 — Método, laboratório e ética

Criptografia protege informação sob hipóteses explícitas; não torna um sistema
automaticamente seguro. Em cada exercício registre: ativo, adversário,
propriedade desejada, material secreto, falha possível e evidência de teste.
Confidencialidade esconde conteúdo; integridade detecta alteração;
autenticidade liga uma mensagem a uma chave; disponibilidade e autorização
exigem outros controles.

Use apenas dados sintéticos. Chaves do curso são descartáveis e nunca entram em
repositórios, logs ou capturas. Algoritmos de brinquedo servem para observar a
matemática, não para proteger dados. Compare resultados com vetores conhecidos,
teste alterações e trate erro de autenticação como falha fechada.
