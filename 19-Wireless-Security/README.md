# 19 — Criptografia I: fundamentos, matemática, hashes e MACs

Primeira etapa de uma formação completa em criptografia. Parte de bits,
representação e objetivos de segurança; constrói a matemática necessária; e
chega a aleatoriedade, hashes, HMAC, KDFs e armazenamento de senhas.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Estudantes e desenvolvedores que nunca estudaram criptografia formalmente. |
| Pré-requisitos | Módulos 00 e 02; álgebra básica e Python introdutório. |
| Tempo estimado | 120–180 horas. |
| Ambiente | Python padrão, fixtures locais e cálculos didáticos sem dados reais. |
| Evidência final | Caderno matemático, utilitários testados e projeto de integridade. |
| Critério de conclusão | Explicar propriedades, selecionar hash/MAC/KDF e reconhecer usos incorretos. |
