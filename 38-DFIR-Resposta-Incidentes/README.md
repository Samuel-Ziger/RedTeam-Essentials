# 38 — DFIR e resposta a incidentes

Esta etapa fecha o ciclo operacional: preservar, investigar, conter, erradicar,
recuperar e aprender. Os artefatos locais conectam as ações dos módulos
anteriores às evidências que um time defensivo realmente observa.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | SOC, DFIR, administração, resposta a incidentes e Purple Team. |
| Pré-requisitos | Módulos `27`, `31`, `32`, `33`, `35`, `36` e `37`. |
| Tempo estimado | 40–64 horas. |
| Ambiente | Fixtures sintéticas, imagens e logs de sistemas próprios. |
| Foco | Preservação, timeline, hipótese, contenção e comunicação. |
| Evidência final | Relatório forense com cadeia de custódia e plano de recuperação. |
| Critério de conclusão | Timeline reproduzível, decisões justificadas e relatório revisado. |
