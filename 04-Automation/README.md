# 04 — Automação profissional

> Engenharia de automações seguras, idempotentes, observáveis e operáveis.

> **Transição curricular:** a engenharia de ferramentas de segurança continua
> no [módulo 28](../28-Engenharia-Ferramentas-Seguranca/README.md).

## Contrato do módulo

| Campo | Definição |
|-------|-----------|
| Público | Programadores que concluíram os módulos 00–03 e querem automatizar processos com confiabilidade. |
| Pré-requisitos | Módulos 00–03. |
| Tempo estimado | 220–320 horas. |
| Ambiente | Desenvolvimento local, serviços simulados e CI isolada. |
| Evidência final | Automação com dry-run, idempotência, testes, auditoria e runbook. |
| Critério de conclusão | Atingir pelo menos 75% na rubrica e demonstrar os controles essenciais no projeto FileFlow. |

## Formação-base

Acesse **[automacao-profissional/README.md](automacao-profissional/README.md)**.
São 15 capítulos aprofundados, 30 práticas, cinco laboratórios progressivos,
exemplos nas cinco linguagens e o projeto FileFlow com 16 testes. A rota cobre
decisão, plan/apply, pipelines, integrações, jobs, resiliência, concorrência,
segurança, observabilidade, testes, CI/CD, distribuição e operação. Sistemas
Operacionais permanecem fora do escopo.

```bash
bash 04-Automation/automacao-profissional/testar-curso.sh
```
