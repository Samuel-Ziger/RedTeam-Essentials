# 02 — X.509 por dentro

Um certificado contém versão, serial, emissor, validade, sujeito, chave pública,
extensões e assinatura. DER é a codificação binária canônica; PEM encapsula DER
em Base64 com marcadores. O certificado é público; sua chave privada é separada.

Extensões críticas desconhecidas devem causar rejeição. Basic Constraints,
Key Usage, Extended Key Usage, Subject Alternative Name, Name Constraints,
Authority/Subject Key Identifier e políticas mudam como o certificado pode ser
usado. Ler apenas CN e validade não é auditoria suficiente.

## Prática

Use o auditor local para produzir um inventário, não uma conclusão automática
de confiança.
