# Criptografia III — PKI, TLS e proteção aplicada

Criptografia aplicada é uma disciplina de ciclo de vida: identidade, emissão,
validação, rotação, revogação, observabilidade e recuperação. O curso trata
configuração e diagnóstico sem simular interceptação de terceiros.
