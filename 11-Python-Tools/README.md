# 11 — Windows empresarial II: engenharia, identidade e segurança

> Imagens, deployment, políticas, AD/GPO, PKI, JEA, App Control, Defender,
> credenciais, telemetria, compliance e continuidade em escala.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Engenheiros Windows, identidade, endpoint e segurança. |
| Pré-requisitos | Módulos 08–10. |
| Tempo estimado | 240–360 horas. |
| Ambiente | Windows Client/Server oficiais em VMs e fixtures offline. |
| Evidência final | Pipeline de imagem, baseline, modelo de identidade e capstone. |
| Critério de conclusão | Defender arquitetura, rollout, drift e recuperação. |

## Curso principal

Siga [windows-empresarial-avancado/](windows-empresarial-avancado/README.md).
São 22 capítulos, sete labs e ferramentas PowerShell que comparam baseline e
validam identidades/grupos/permissões inteiramente offline.

AD DS, GPO, gMSA, LAPS, AD CS, Autopilot/Intune, Defender for Endpoint e
clustering são ensinados em arquitetura e governança. A implantação distribuída
aguarda redes, evitando configurar identidade empresarial sem DNS, tempo,
protocolos e segmentação corretamente compreendidos.
