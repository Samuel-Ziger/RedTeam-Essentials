# Lab 01 — Pipeline de imagem

1. Copie uma WIM evaluation oficial e registre hash/origem.
2. Liste índices e escolha explicitamente um.
3. Monte read-only em diretório vazio.
4. Exporte packages, features e drivers.
5. Desmonte com `/Discard`.
6. Confirme hash da WIM inalterado.
7. Escreva pipeline de servicing em cópia, sem executá-lo no host.

**Aprovação:** comandos, logs, manifesto e cleanup; nenhuma ISO/WIM no Git.
