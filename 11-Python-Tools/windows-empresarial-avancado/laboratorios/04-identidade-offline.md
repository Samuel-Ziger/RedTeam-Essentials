# Lab 04 — Identidade offline

Amplie a fixture com duas personas, contas de serviço, grupos funcionais e
grupos de acesso. Toda identidade/grupo precisa de owner. Permissão aponta para
grupo de acesso, não diretamente para pessoa.

Injete grupo cíclico, membro desconhecido e owner vazio; confirme detecção e
corrija. Produza diagrama OU/grupos/delegação e lista de dependências de redes
para futura implantação.
