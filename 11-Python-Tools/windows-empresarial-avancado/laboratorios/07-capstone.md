# Lab 07 — Capstone empresarial

Execute o projeto do capítulo 21. O avaliador introduzirá quatro drifts nas
fixtures. Detecte e gere planos; nenhuma correção automática é permitida.

Conduza tabletop de update incompatível, perda de servidor, perda de identidade
e corrupção replicada. Declare o que pode ser testado offline e quais contratos
precisam do módulo de redes.

**Aprovação:** arquitetura reproduzível, sem secrets/dados reais, com owners,
gates, rollback, RPO/RTO, exceções e cleanup.
