# Lab 02 — Unattend seguro

Crie `autounattend.xml` para VM descartável com locale, edition selecionada e
OOBE mínimo. Não inclua senha, product key, token, script remoto ou limpeza de
disco genérica.

Valide XML, passes e settings com ADK/WSIM correspondente. Faça code review e,
somente em clone, execute Setup. Colete `setupact.log`/`setuperr.log`, confirme
resultado e destrua a mídia de resposta.
