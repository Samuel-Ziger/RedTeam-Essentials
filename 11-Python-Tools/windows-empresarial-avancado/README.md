# Windows empresarial II — engenharia, identidade e segurança em escala

Especialização em engenharia de imagens, políticas, identidade Windows,
PowerShell governado, Application Control, Defender, telemetria, compliance e
continuidade. Tópicos que dependem de conectividade são modelados offline e só
serão implantados depois do módulo de redes.

## Contrato de aprendizagem

| Campo | Definição |
|---|---|
| Nível | Intermediário a avançado empresarial |
| Duração | 240–360 horas |
| Pré-requisito | Módulos 08–10 |
| Ambiente | VMs Windows Client/Server oficiais e fixtures offline |
| Evidência | Imagem versionada, baseline, modelo de identidade e capstone |
| Conclusão | Projetar escala, defesa e recuperação com rastreabilidade |

## Fronteira de implantação

AD DS, GPO de domínio, AD CS, LAPS, gMSA, Intune, Autopilot, Defender for
Endpoint, WSUS e clustering aparecem como arquitetura e governança. Promoção
de controlador, DNS, DHCP, portas, firewall, trust, replicação, remoting e
cluster real aguardam redes. Isso evita ensinar um ambiente empresarial quebrado.
