# Glossário

- **ADK/WinPE:** kit de deployment e ambiente mínimo de pré-instalação.
- **AD DS:** diretório de domínio Windows.
- **ADMX/ADML:** definições e recursos localizados de política administrativa.
- **App Control:** allowlist/enforcement de código no Windows.
- **Autopilot:** serviço de provisionamento de dispositivos Windows.
- **CSP:** interface de configuração usada por MDM.
- **Drift:** diferença entre observado e desejado.
- **FSMO:** papéis de operação single-master do AD.
- **GPC/GPT:** partes de diretório e SYSVOL de uma GPO.
- **gMSA:** conta de serviço gerenciada em grupo.
- **JEA:** endpoint PowerShell com capacidades administrativas restritas.
- **LAPS:** gestão de senha de administrador local.
- **OSConfig:** mecanismo/baseline de configuração do Windows Server suportado.
- **WIM:** formato de imagem Windows baseado em arquivos.
- **WSIM:** editor/validador de answer files do ADK.
