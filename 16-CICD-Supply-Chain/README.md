# 16 — Redes III: switching, VLANs e acesso empresarial

Este módulo explica como uma LAN comutada funciona e como projetar domínios de
broadcast, VLANs, trunks, redundância, agregação, controle de acesso e QoS.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Estudantes e administradores de LANs empresariais. |
| Pré-requisitos | Módulos 14 e 15. |
| Tempo estimado | 150–220 horas. |
| Ambiente | Simulações offline; equipamento próprio é opcional |
| Evidência final | Plano de VLAN, matriz de portas, topologia redundante e validação automatizada. |
| Critério de conclusão | Projetar uma LAN segmentada sem loops nem VLANs implícitas. |
