# 40 — Capstone Purple Team: operações integradas

O capstone integra toda a formação. Uma operação autorizada parte de regras
de engajamento, correlaciona reconhecimento e controles de API, mede a
telemetria defensiva e termina com correção, reteste e apresentação executiva.

> **Bloqueio curricular:** este projeto pressupõe os módulos `27`–`39`, além
> da base obrigatória `00`–`26`.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Estudantes que concluíram a especialização e equipes Purple Team. |
| Pré-requisitos | Todos os módulos `27`–`39`. |
| Tempo estimado | 60–100 horas. |
| Ambiente | Cenário local ou organização explicitamente autorizada. |
| Foco | Planejamento, execução controlada, detecção, resposta e aprendizado. |
| Evidência final | Portfólio Purple Team completo, reproduzível e revisado por pares. |
| Critério de conclusão | Reteste aprovado, risco residual documentado e ambiente restaurado. |

## Critério de conclusão

O trabalho só termina quando achados e controles foram priorizados, as
mudanças foram retestadas, riscos residuais foram aceitos explicitamente e o
ambiente foi devolvido ao estado combinado nas regras de engajamento.
