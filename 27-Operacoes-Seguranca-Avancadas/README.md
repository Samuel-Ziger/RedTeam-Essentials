# 27 — Especialização avançada: governança, laboratório e evidência

Este módulo é a porta de entrada da especialização em segurança. Ele não
repete a formação de `00` a `26`: transforma essa base em um processo seguro,
autorizado, reproduzível e sustentado por evidências.

> **Bloqueio curricular:** conclua os módulos `00`–`26` antes de iniciar esta
> etapa. Conhecimento de programação, sistemas, redes, criptografia, privacidade
> e controles Purple Team é pressuposto, não reensinado aqui.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Estudantes que concluíram a formação-base e profissionais de segurança. |
| Pré-requisitos | Todos os módulos `00`–`26`. |
| Tempo estimado | 20–30 horas. |
| Foco | RoE, escopo, laboratório isolado, cadeia de evidência e critérios de parada. |
| Ambiente | Somente sistemas próprios ou explicitamente autorizados. |
| Evidência final | Dossiê de operação com escopo, topologia, riscos, logs, hashes e encerramento. |
| Critério de conclusão | Dossiê revisado, gate de prontidão aprovado e laboratório restaurável. |

## Resultado esperado

Ao concluir, o aluno consegue decidir se uma atividade pode começar, registrar
o que está autorizado, proteger dados e segredos, produzir evidência verificável
e interromper o trabalho quando os limites definidos forem atingidos.
