# Governança, laboratório e evidência

Este índice converte fundamentos já estudados em um gate operacional para toda
a especialização. A sequência deve ser seguida antes de qualquer atividade dos
módulos `28`–`40`.

## Critério de conclusão

Entregue RoE, diagrama do laboratório, classificação dos dados, convenção de
evidências, critérios de parada e plano de limpeza. Se autoridade ou escopo não
puderem ser provados, a atividade não começa.
