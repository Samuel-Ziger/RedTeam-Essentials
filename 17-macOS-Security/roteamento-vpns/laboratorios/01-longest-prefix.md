# Lab 01 — Longest-prefix e rotas

Preveja o resultado para dez destinos usando `routes.json`; depois execute o
simulador. Adicione duas rotas do mesmo prefixo com preferência/métrica distintas
e uma default. Modele rota null de sumarização.

**Aceite:** prefixo mais específico é avaliado antes de preferência/métrica e
next hop pertence à mesma família IP.
