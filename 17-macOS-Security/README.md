# 17 — Redes IV: roteamento, WAN, VPN e políticas

Formação intermediária/avançada sobre encaminhamento IP, rotas estáticas,
OSPF, BGP, VRF, NAT, ACLs, firewalls, VPNs e alta disponibilidade.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Administradores e engenheiros de roteamento, WAN e acesso remoto. |
| Pré-requisitos | Módulos 14–16. |
| Tempo estimado | 180–280 horas. |
| Ambiente | Modelos e simuladores offline; VPN apenas entre ativos próprios |
| Evidência final | Tabela de rotas, política, desenho WAN/VPN e runbook de falha. |
| Critério de conclusão | Projetar conectividade entre redes com segurança e redundância. |
