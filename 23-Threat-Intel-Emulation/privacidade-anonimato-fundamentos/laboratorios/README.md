# Laboratórios do módulo 23

Todos os exercícios usam desenhos, configurações locais ou dados sintéticos.
Não capture tráfego de terceiros e não tente identificar pessoas.

| Lab | Tema | Evidência |
|---:|---|---|
| 01 | [Matriz de observadores](01-matriz-observadores.md) | tabela de visibilidade e premissas |
| 02 | [Inventário de metadados](02-inventario-metadados.md) | ciclo de vida e minimização |
| 03 | [Navegador e estado local](03-navegador-estado.md) | comparação controlada |
| 04 | [VPN, proxy e Tor](04-comparar-arquiteturas.md) | decisão baseada em ameaça |
| 05 | [Projeto de privacidade](05-projeto-privacidade.md) | pacote final revisável |

Use um diretório temporário para anotações que contenham dados do seu ambiente.
As evidências publicadas no Git devem ser sanitizadas.
