# 32 — Segurança em nuvem: AWS, Azure e GCP

Esta etapa estuda identidade, recursos, telemetria e caminhos de ataque em
nuvem com contas de laboratório e eventos sintéticos. O objetivo é relacionar
configuração, evidência e controle compensatório entre provedores.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Cloud security, plataforma, DevSecOps, SOC e Purple Team. |
| Pré-requisitos | Módulos `27`, `29` e `31`. |
| Tempo estimado | 40–60 horas. |
| Ambiente | Fixtures locais ou tenant/projeto próprio com limites de custo. |
| Foco | IAM, exposição, trilhas de auditoria e remediação verificável. |
| Evidência final | Mapa de risco multicloud e análise reproduzível de eventos. |
| Critério de conclusão | Lab multicloud concluído e matriz de controles retestada. |
