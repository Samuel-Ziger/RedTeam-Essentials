# Glossário

| Termo | Definição curta |
|---|---|
| abstração | contrato que retém o essencial e oculta detalhes |
| acoplamento | grau de dependência entre partes |
| ADR | registro versionado de uma decisão arquitetural |
| algoritmo guloso | estratégia que escolhe a melhor opção local sem desfazer a decisão |
| análise amortizada | custo médio garantido por operação ao longo de uma sequência |
| aresta | relação entre dois vértices de um grafo |
| atributo de qualidade | propriedade mensurável como latência, disponibilidade ou modificabilidade |
| backtracking | busca que aplica e desfaz escolhas |
| Big O | limite assintótico superior de crescimento |
| Big Omega | limite assintótico inferior de crescimento |
| Big Theta | limite assintótico simultaneamente superior e inferior |
| BFS | busca em largura que expande a fronteira por níveis |
| characterization test | teste que registra comportamento existente antes de uma mudança |
| caminho crítico | caminho de maior duração num DAG de dependências ponderadas |
| complexidade espacial | crescimento da memória necessária em função da entrada |
| complexidade temporal | crescimento da quantidade de operações em função da entrada |
| composition root | ponto único em que implementações e dependências são montadas |
| coesão | proximidade de responsabilidades dentro de um módulo |
| contrato | comportamento, entradas, saídas e garantias observáveis |
| DAG | grafo dirigido sem ciclos |
| DFS | busca em profundidade que explora um caminho antes de voltar |
| dublê de teste | substituto controlado como fake, stub, spy ou mock |
| efeito colateral | alteração observável além do valor retornado |
| entidade | objeto de domínio distinguido por identidade |
| estabilidade | propriedade de uma ordenação que preserva a ordem relativa dos empates |
| fake | implementação funcional simplificada usada em teste |
| fila de prioridade | estrutura que remove o elemento de maior prioridade, não o mais antigo |
| grafo esparso | grafo com quantidade de arestas muito menor que o máximo possível |
| heap | árvore parcial usada como fila de prioridade |
| idempotência | repetir uma operação produz o mesmo efeito final |
| imutabilidade | impossibilidade de alterar um valor depois de construído |
| injeção de dependência | fornecimento externo de uma colaboração em vez de construção oculta |
| invariante | propriedade que deve permanecer verdadeira |
| lista de adjacência | representação que armazena os vizinhos de cada vértice |
| matriz de adjacência | matriz em que cada célula representa a presença/peso de uma aresta |
| memoização | cache de resultados de chamadas por estado |
| mock | dublê que verifica interações esperadas |
| mutation testing | avaliação da suíte por alterações deliberadas no programa |
| mutabilidade | capacidade de alterar um valor após criação |
| oráculo de teste | mecanismo independente que decide se um resultado está correto |
| ordenação topológica | ordem linear que posiciona toda origem antes do destino de uma aresta |
| ownership | regra sobre quem controla, modifica e encerra o ciclo de vida de um recurso |
| percentil | valor abaixo do qual cai determinada fração das observações |
| porta | contrato pelo qual o núcleo interage com uma borda |
| pós-condição | garantia após uma operação bem-sucedida |
| pré-condição | condição exigida antes da operação |
| programação dinâmica | resolução de estados sobrepostos com armazenamento de resultados |
| propriedade metamórfica | relação esperada entre saídas após transformar a entrada |
| refactoring seam | ponto em que uma dependência pode ser substituída de forma controlada |
| refatoração | mudança interna sem mudança intencional de comportamento |
| repositório | abstração de acesso a uma coleção do domínio |
| requisito funcional | capacidade ou comportamento que o sistema deve fornecer |
| resiliência | capacidade de limitar impacto e recuperar-se de falhas previstas |
| runbook | procedimento operacional reproduzível para rotina ou incidente |
| SARGability | possibilidade de um predicado aproveitar uma estrutura de busca/indexação |
| SOLID | conjunto de heurísticas para responsabilidades e dependências em design OO |
| SLO | objetivo mensurável de nível de serviço |
| stub | dublê que fornece respostas predeterminadas |
| tabela hash | estrutura que distribui chaves por uma função hash |
| teste de contrato | suíte comum que verifica implementações de uma mesma porta |
| teste de propriedade | teste de regras gerais sobre muitas entradas geradas |
| test trophy | estratégia que enfatiza integrações e contratos com unitários direcionados |
| trie | árvore orientada a prefixos |
| valor | objeto definido pelos seus atributos, sem identidade independente |
| variante de laço | quantidade que progride estritamente em direção ao término |
| vértice | elemento relacionado em um grafo |
