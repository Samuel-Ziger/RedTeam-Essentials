# 15 — Redes II: redes domésticas, Wi-Fi e pequenos escritórios

Formação prática para projetar, configurar, proteger, documentar e solucionar
problemas de uma rede residencial ou de pequeno escritório, sem depender da
interface de um fabricante específico.

## Contrato do módulo

| Campo | Definição |
|---|---|
| Público | Usuários, suporte e administradores de redes residenciais/SOHO. |
| Pré-requisitos | Módulo 14. |
| Tempo estimado | 120–180 horas. |
| Ambiente | Roteador próprio ou diagrama/fixture offline |
| Evidência final | Inventário, plano Wi-Fi, segmentação e runbook de recuperação. |
| Critério de conclusão | Entregar uma rede doméstica segura, mensurável e recuperável. |
