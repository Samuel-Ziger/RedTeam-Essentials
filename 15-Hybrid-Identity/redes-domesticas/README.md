# Redes II — redes domésticas, Wi-Fi e pequenos escritórios

O objetivo é transformar uma “caixa da operadora” em uma infraestrutura
compreendida, documentada, segura e recuperável. Os conceitos valem para
diferentes fabricantes; nomes de telas mudam, responsabilidades não.
