# Glossário

- **ADE:** Automated Device Enrollment, registro organizacional no Setup Assistant.
- **ABM:** Apple Business Manager, serviço para propriedade, apps e integração.
- **Bootstrap Token:** credencial institucional custodiada pelo MDM para operações autorizadas.
- **Code Requirement:** expressão que identifica propriedades esperadas de código assinado.
- **DDM:** Declarative Device Management, estado desejado e status no dispositivo.
- **Darwin:** base open source do sistema, incluindo XNU e componentes Unix.
- **dyld:** carregador dinâmico de Mach-O.
- **Endpoint Security:** API autorizada para clientes defensivos de eventos do sistema.
- **Entitlement:** capacidade assinada concedida a um processo.
- **IOKit:** modelo e frameworks de I/O e drivers do ecossistema Darwin.
- **Mach-O:** formato de executáveis, bibliotecas e objetos do macOS.
- **Mach port:** endpoint protegido para comunicação e capacidades Mach.
- **MDM:** protocolo/serviço de gerenciamento de dispositivos Apple.
- **Notarização:** análise automatizada da Apple para software distribuído fora da loja.
- **Platform SSO:** integração de identidade organizacional com login e sessão no Mac.
- **Secure Token:** atributo ligado à autorização de operações APFS/FileVault.
- **Slice:** representação de uma arquitetura em binário universal.
- **System Extension:** extensão gerenciada no espaço do usuário em lugar de kext quando possível.
